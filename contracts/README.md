# Poons contracts

- `src/Poons.sol` — ERC721, one Poon per wallet via `drop(address[])`, 3,333 max, 5% creator fee (ERC2981 + ERC721-C transfer validator for OpenSea).
- `src/PoonsRenderer.sol` — fully on-chain SVG + JSON metadata; data lives in the linked `PoonsData` library (generated by `art/export-sol.js`).
- `src/mock/MockPons.sol` — testnet-only stand-in for the Pons curve (same events as mainnet).

```sh
forge test && forge build --sizes
forge test --match-path "test/fork/*" --fork-url https://rpc.mainnet.chain.robinhood.com
./deploy.sh testnet | mainnet
```
